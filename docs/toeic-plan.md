## Part1 / Part2 / Part3 / Part4 メディア

| Part | CATEGORY | 置き場 | ファイル |
|---|---|---|---|
| 1 | 11 | `backend/image/TOEIC-1/` | `{N}.png` + `{N}-A`…`D.mp3`（4択） |
| 2 | 21 | `backend/image/TOEIC-2/` | `{N}-Q.mp3` + `{N}-A`…`C.mp3`（3択） |
| 3 | 31 | `backend/image/TOEIC-3/` | `{FLAG}.mp3` / `{FLAG}.png`（FLAG=セット先頭。3問とも同じ） |
| 4 | 41 | `backend/image/TOEIC-4/` | `{FLAG}.mp3` / `{FLAG}.png`（FLAG=セット先頭。例 401 / 404） |

- Part2 の DB: A1–A3=応答、**A4=英文の質問文**（選択肢ではない）
- 音声ファイル名は **元の A1〜A3**。表示時は permutation で付け替え（A4 はシャッフルしない）
- 出題時: 選択肢テキスト非表示（音声のみ）。設問音声（Part2 の Q）は表示
- 解説時: 設問プレーヤーの横に A4 の英文を表示
- 再生回数: 各クリップ 1回（`max_audio_plays: 1`）。解説は制限なし

### Part3 / Part4 セット

- DB: 同一セットの3行は同じ `FLAG`（=先頭 `NUMBER`）。P3 は 301–399、P4 は 401–499（西検共有帯 201–299 と分離）
- 出題: FLAG グループからセット抽出。分野別5問は **3問＋2問固定**（各ブロック先頭に音声付き。案内は Q1 / Q4）
- 再生: **1回のみ**。分野別はセット先頭のみプレーヤー（続きは「問題Nで再生…」、再生済みならその旨）。一問一答は全問で再生可能
- 図: `{FLAG}.png` をセット内3問すべてで表示（任意）
- 解説: 共有音声・図を表示（セット案内文は出さない）
- 一問一答 (93/94): 当面1問（セット単位 UI は後続）
