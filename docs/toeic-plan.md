## Part1 メディア

- カテゴリ: **11 のみ**（当面）
- 画像: `backend/image/{NUMBER}.png`
- 音声: 同じ場所の `{NUMBER}-A.mp3` … `{NUMBER}-D.mp3`（**元の A1〜A4** に対応）
- 表示時は examlist の permutation でテキストと同じ順に音声を付け替え
- 出題時: 写真＋各選択肢の音声のみ（テキスト非表示、再生は各1回）
- 解説時: テキストも表示（再生制限なし）
